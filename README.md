# Gautham D. — Portfolio Website

Personal developer portfolio for **Gautham D.**, an Artificial Intelligence & Data Science undergraduate, showcasing my education, skills, internships, and certifications.

🔗 **Live Site:** [https://gautham-portfolio-lanzhan.netlify.app/](#) <!-- replace with your Netlify/GitHub Pages link -->

## 📌 About

A fully responsive, single-page portfolio built to highlight my journey in AI, Machine Learning, and Data Science — including my academic background, internship experience, and completed certifications.

## 🛠️ Built With

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- [AOS](https://michalsnik.github.io/aos/) — Animate on Scroll library

## ✨ Features

- Fully responsive design (mobile, tablet, desktop)
- Animated hero section with a play/pause intro video
- Scroll-reveal animations throughout
- Interactive certificate viewer — click "View Certificate" to see the full image
- Timeline-based education section
- Internship experience cards with real company logos
- Skills organized by category (AI & ML, Data Science, Programming, Tools)
- Direct contact links: email, phone, GitHub, LinkedIn, Instagram

## 🚀 Getting Started (Run Locally)

1. Clone this repository
   ```bash
   git clone https://github.com/gauthamdhivakar-000/gautham-portfolio.git
   ```
2. Open the project folder
   ```bash
   cd gautham-portfolio
   ```
3. Open `index.html` directly in your browser — no build step, no dependencies to install.

## 🌐 Deployment

This site is a static build, so it can be deployed anywhere for free:

- **Netlify** — drag and drop the folder at [app.netlify.com/drop](https://app.netlify.com/drop)
- **GitHub Pages** — push this repo, then enable Pages in **Settings → Pages**
